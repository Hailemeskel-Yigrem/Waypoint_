# Environments

| Variable       | Description                  |
| -------------- | ---------------------------- |
| `DATABASE_URL` | PostgreSQL connection string |
| `REDIS_URL`    | Redis connection for worker  |
| `JWT_SECRET`   | Token signing secret         |
| `LOG_LEVEL`    | info/debug/warn/error        |
| `VITE_API_URL` | Browser API base URL         |
